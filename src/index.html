Catalyst 2.0.0-beta.1

9 September 2026

The pre-season release: built against the platform the 2027 season will run on, so your team can port over the offseason instead of in January.

Not for a robot you are competing with. It has never been driven on a robot. It has run on a bench — a Pigeon on can_s0, the onboard IMU, the board's own status topics — but swerve, mechanisms, autos and vision have not moved a robot. Its 867 tests pass with no failures; none of them drives one. It is also a beta pinned to a WPILib alpha that has changed Mechanism from an interface to a class and back across three builds. Pre-season and offseason robots only.

Competing this season? Stay on Catalyst 1.x — tag v1.12.0, WPILib 2026, roboRIO.

Import a project

Any WPILib project, already written, whether or not Catalyst is in it. Pick the folder with build.gradle in it and Catalyst reads it and reports what it found — season, installed Catalyst version, where that library resolves from, and the rest of vendordeps. It writes nothing and changes nothing. To add Catalyst to a project, use the Library page instead.

Registered

What an agent can do

An agent can always read a registered project and search its knowledge graph. It can write only where you have switched it on, and never inside .git, build, target or node_modules even then. Nothing outside a registered folder is reachable at all. The workspace's Claude session is bound by the same rules.
