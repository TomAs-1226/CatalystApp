Install into your robot project

Point Catalyst at your GradleRIO project and it drops the vendordep straight in. The library installs from the copy bundled in this app, so it works with no internet.

What this installs. The bundled vendordep points at v2.0.0-beta.1, and everything the app advertises is in it — Motor History, Autonomy 2.0, the decision cores. It fetches from JitPack like any other vendordep.

It needs WPILib 2027 alpha-7 and Systemcore OS beta 14, and that pairing is not optional: a build made against alpha-7 aborts on beta 13 before your robot code runs. Flash the OS first.

It is a beta and it has never been driven on a robot — pre-season and offseason robots only. If you are competing this season, install Catalyst 1.x (tag v1.12.0) instead.

Your projects

The robot projects Catalyst knows about on this machine. What you see here is exactly what an AI agent sees through the bundled MCP server — and writing is off until you say otherwise, per project.

Import a project

Any WPILib project, already written, whether or not Catalyst is in it. Pick the folder with build.gradle in it and Catalyst reads it and reports what it found — season, installed Catalyst version, where that library resolves from, and the rest of vendordeps. It writes nothing and changes nothing. To add Catalyst to a project, use the Install page instead.

Registered

What an agent can do

An agent can always read a registered project and search its knowledge graph. It can write only where you have switched it on, and never inside .git, build, target or node_modules even then. Nothing outside a registered folder is reachable at all.

Connect an AI agent

Catalyst ships a small server that lets AI agents (Claude Desktop, Claude Code, Cursor…) use these tools, read the bundled Catalyst knowledge graph, and build and query a graph of your own project. It runs on your machine over stdio with no npm dependencies and no internet, so it starts wherever Node does. Give it access to your own code on the Projects page — reading is immediate, writing is off until you switch it on per project.
